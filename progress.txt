## Codebase Patterns

- Builtin types are defined in `src/core/compile/builtin/` with separate modules for prelude, python, etc.
- Each builtin module has a `namespace()` function that returns a BTreeMap of names to NamespacedObjects
- The `Builtin` enum in `mod.rs` wraps all builtin variants and `match_builtin!` macro dispatches to them
- Type helpers like `Ty::prelude()` and `Ty::python()` are in `src/core/compile/check/mod.rs`
- Module registration happens in `src/core/preprocess/mod.rs` with the `Module` enum
- Generated code templates are in `src/core/generate/mod.rs` using `quote!` macro
- Data files live in `data/const/` and are included via macros in `src/data.rs`
- **E2E workflow**: `seahorse init` → write .py → `seahorse compile` → split output files → `anchor build`
- **blake3 compatibility**: Pin blake3 to =1.8.2 in generated Cargo.toml (v1.8.3+ requires edition 2024 unsupported by Solana BPF toolchain)
- **Reference programs**: Find idiomatic Anchor programs first, then write Seahorse equivalents to match
- **Testing stack**: Mollusk for unit tests, LiteSVM for integration tests, TypeScript secondary

- **Solana SDK versioning**: Use solana-sdk 2.2.x with mollusk-svm 0.1.x for Anchor 0.32 compatibility. SDK 3.0+ is only available in the modular crate ecosystem (solana-account, solana-pubkey, etc.) and requires Anchor 1.0+
- **Mollusk versions**: 0.0.x uses solana-sdk 2.1, 0.1.x uses solana-sdk 2.2, 0.8+ uses modular crates v3.x
- **Mollusk API (v0.1.x)**: Uses Account type (not AccountSharedData). Need ReadableAccount trait for .lamports()
- **Anchor discriminators**: Use sha256("account:<AccountName>")[..8] for accounts, sha256("global:<instruction_name>")[..8] for instructions
- **LiteSVM versions**: 0.3.x uses solana-sdk ~2.0, 0.4.x-0.5.x uses solana-sdk 2.1, 0.6.x uses modular crates 2.2, 0.7+ uses modular crates 3.x
- **LiteSVM API (v0.6.x)**: Uses solana modular crates (solana-account, solana-pubkey, etc.) at 2.2.x. TransactionResult is Result<TransactionMetadata, FailedTransactionMetadata>
- **anchor-litesvm compatibility**: v0.2.0 requires anchor-lang 0.31.1, v0.3.0 requires anchor-lang 1.0-rc. Neither compatible with Anchor 0.32.1.
- **TypeScript tests**: Located in tests/ts/, run with `npm test` from that directory. Uses litesvm 0.4.0 npm package with vitest.
- **Build pipeline**: `scripts/build-test-programs.sh` compiles Seahorse examples → builds .so files → outputs to target/deploy/
- **Seahorse compiled output format**: Multi-file with markers `// ===== dot/mod.rs =====`, `// ===== dot/program.rs =====`, `// ===== lib.rs =====`
- **Mutable wrapper in Seahorse**: Compiled code wraps accounts in `Mutable<T>` requiring `.borrow()` for field access in PDA signer seeds
- **Program IDs**: Ensure base58 program IDs decode to exactly 32 bytes (valid base58 address length)
